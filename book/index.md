# DraCor Technical Reports

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24368947.svg)](https://hdl.handle.net/10.5281/zenodo.24368947)

HTML editions of the four technical reports on [DraCor](https://dracor.org) written in work package 7 of the EU project [CLS INFRA](https://clsinfra.io) (Computational Literary Studies Infrastructure, 2021–2025).

Together, the reports document the DraCor system (corpora, API, front end, metrics, versioning and research software) at different points in time.

| Report | Title | Year | Archived version |
|---|---|---|---|
| [D7.1](#clsinfra-d71-index) | On Programmable Corpora. Report and Prototype (DraCor) | 2023 | [10.5281/zenodo.7664964](https://hdl.handle.net/10.5281/zenodo.7664964) |
| [D7.2](#clsinfra-d72-index) | API Libraries for R and Python for the Programmable Corpora Prototype “DraCor”: “rdracor” and “pydracor” | 2023 | [10.5281/zenodo.15302236](https://hdl.handle.net/10.5281/zenodo.15302236) |
| [D7.3](#clsinfra-d73-index) | On Versioning Living and Programmable Corpora | 2024 | [10.5281/zenodo.11081934](https://hdl.handle.net/10.5281/zenodo.11081934) |
| [D7.4](#clsinfra-d74-index) | Report on the Implementation of Programmable Corpora | 2025 | [10.5281/zenodo.15301341](https://hdl.handle.net/10.5281/zenodo.15301341) |

The archived PDFs on Zenodo remain the version of record; please cite them.

The [System Documentation](#docs-index) describes the current DraCor system, building on the reports and updating them. It is being written topic by topic; the first part covers the [front end](#dracor-frontend).

:::{note} Status: 1.1.0-rc.1, preview with editorial notes
This preview adds editorial notes to the reviewed edition 1.0.0: boxes marked “Outdated” or “Update” point out where DraCor has changed since a report was written and link to current resources. The report text itself is unchanged. The archived version on Zenodo is 1.0.0.

All four reports were converted from their original sources and checked page by page against the published PDFs (text, footnote numbering, formatting, figures, tables, code and links). Every deviation from the sources is recorded in the repository.

To cite these editions: Börner, Ingo. *DraCor Technical Reports: HTML editions of the CLS INFRA reports on DraCor (D7.1–D7.4)*. Zenodo. [doi:10.5281/zenodo.24368947](https://hdl.handle.net/10.5281/zenodo.24368947) (all versions).
:::

The editions reproduce the published text with its footnotes, figures, tables and code (shown with the original output as of the report date). Page layout, page numbers, tables of contents and the appendices of D7.2 are not reproduced.
